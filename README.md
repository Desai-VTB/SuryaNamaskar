# SuryaNamaskar
**Surya Namaskar Voice Guide** is a browser-based Chrome application hosted on GitHub that provides a simple, guided way to practise **Surya Namaskar (Sun Salutation)** using voice instructions.

The application guides the user through each step and posture of Surya Namaskar with **clear audio/voice prompts**, helping them maintain the correct sequence, timing, breathing rhythm, and transitions without needing to constantly look at a screen.

Designed to support both beginners and regular practitioners, the app acts like a **personal voice-guided Surya Namaskar instructor**—allowing users to focus on their movement, breathing, and awareness while the application guides them through the practice.

**Key features include:**

* Voice-guided instructions for each Surya Namaskar posture
* Guidance on breathing and movement coordination
* Step-by-step sequencing and timing
* Hands-free practice with minimal screen interaction
* Simple, lightweight Chrome-based interface
* Openly hosted on GitHub for easy access and use

The goal is to make Surya Namaskar **easy to follow, consistent, and accessible**, enabling users to practise independently with the support of real-time voice guidance.
